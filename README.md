# Rust Examples from *Types and Programming Languages*

This repo contains my own implementations of the toy languages and examples from *Types and Programming Languages* by
Benjamin C. Pierce. Pierce provides OCaml implementations on the book's website,
https://www.cis.upenn.edu/~bcpierce/tapl/.

The code is organized as a Cargo workspace with a crate for each implementation.
